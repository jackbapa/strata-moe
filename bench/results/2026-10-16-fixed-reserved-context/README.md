# 32K／64K／128K／256K 完整预留实测

2026-10-16，Windows、Ryzen Threadripper 3960X、128 GiB RAM、GPU 0 RTX 2080 Ti（驱动报告 22,528 MiB）。主模型为同一个 Unsloth Qwen3.6-35B-A3B UD-IQ3_S，MTP 为匹配的 ggml-org Q8_0，K2。主模型专家全部驻留 GPU，使用适配的 Strata 分组 IQ 专家核。引擎 SHA-256：`6b1088ab790058ee27f4b830ce9b95bd42f8de0cef5a2b4430ec2713fb897e34`。

每档都提前分配对应的完整 KV 容量，关闭按需分档。32K／64K／128K 用 F16 KV，256K 用 Q8_0 KV，与发布配置的格式选择一致。每个请求的输入固定为 8K token（8,192），输出 128 token，贪心采样；输入来自重复的 `Explain mixture of experts briefly.` token 序列。因此它是预留容量对照，不是接近 128K／256K 的长输入吞吐测试。

按 32K→64K→128K→256K 的顺序跑三轮，每次启动独立引擎进程；`READY` 后开始请求计时。12 个请求实际输出均为 128 token，输出 token SHA-256 全部一致；每次 MTP 均接受 84/84 个草稿 token。日志核对了每档目标及草稿的实际 KV cells，分别等于 32K、64K、128K、256K。

| 预留上下文 | 整卡显存峰值 | 输出峰值 | 输出中位数 | 首个模型 token 最快／中位数 | 预填充中位数 | 进程 RSS 峰值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 32K | 16,235 MiB | 103.84 token/s | 103.07 token/s | 4.267／4.297 s | 1,907.78 token/s | 1,482.6 MiB |
| 64K | 17,095 MiB | 103.65 token/s | 103.05 token/s | 4.295／4.311 s | 1,902.28 token/s | 1,646.3 MiB |
| 128K | 18,819 MiB | 110.33 token/s | 103.12 token/s | 4.101／4.400 s | 1,865.17 token/s | 1,972.4 MiB |
| 256K | 20,474 MiB | 102.20 token/s | 95.83 token/s | 4.199／4.608 s | 1,780.95 token/s | 2,630.2 MiB |

显存为 200 ms 间隔的 `nvidia-smi` 整卡采样，起始基线约 90 MiB，包含驱动分配；没有把显卡容量限到表中峰值，也没有在物理 16／18／20 GiB 卡上测试。首个模型 token 从发送 `GEN` 算起，不含加载，不是 HTTP 首字节。峰值速度、中位数、显存峰值分别汇总，未要求来自同一轮。

此前仅加减 KV 的显存估算漏掉了计算缓冲。实际日志如下，主模型 GPU 权重 13,032.66 MiB、草稿 GPU 权重 1,372.68 MiB 不变：

| 预留上下文 | 目标 + 草稿 KV | 目标 + 草稿 GPU 计算缓冲 |
| --- | ---: | ---: |
| 32K | 704 MiB | 608.22 MiB |
| 64K | 1,408 MiB | 764.22 MiB |
| 128K | 2,816 MiB | 1,080.22 MiB |
| 256K | 2,992 MiB | 2,560.74 MiB |

因此 32K→256K 的实际整卡峰值增加 **4,239 MiB（4.14 GiB）**，不是先前估算的约 2 GiB。256K 档的 Q8 KV 减少了 KV 增长，但计算缓冲仍继续增长。模型 40 层中每四层有一层完整注意力，其余层使用循环状态，所以不能将整个模型显存按上下文倍数相乘。

这轮速度与历史报告的峰值不同。当前三轮中 128K 的第三轮采样到 1,920 MHz SM 时钟，其余轮的最高采样值为 1,350 MHz；GPU 时钟未锁定，不应把 128K 较高峰值解释成更长预留提高了速度。历史矩阵未逐轮保存二进制及同等时钟采样，现有证据不足以确定两轮速度差异的全部原因。本报告保留同一二进制、相同输入、精确参数、环境变量及每轮遥测，不把旧报告速度合入本表。

后续完成了[相同 50K 输入的按需／固定 KV 对照](../2026-10-16-50k-kv-allocation-ab/README.md)：本轮默认按需输出峰值 100.56 token/s，固定预留峰值 84.70 token/s；原先默认配置的 121.62 token/s 未复现，原因未完全确定。固定预留测试的速度不能直接当成默认 auto 配置的速度。

