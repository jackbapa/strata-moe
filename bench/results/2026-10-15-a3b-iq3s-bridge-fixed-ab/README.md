# IQ3_S A3B: fixed MTP prefill bridge, 50K/256

This exploratory same-executable comparison used GPU 0 (RTX 2080 Ti,
22,528 MiB), a 262,144-token configured context, an exact uncached 50,000-token
prompt, 256 output tokens, Q8 KV, the same Qwen3.6-35B-A3B UD-IQ3_S GGUF and
Q8_0 MTP K2 head. Q6_K dense tensors belong to that **same** IQ3_S GGUF.
The executable SHA-256 was
`05802fa88d8b9a7e865b24bed82f15828eb52ad15d4609e76f91c1f4617fc390`.
Both arms generated byte-identical answers (SHA-256
`c1d52a6c58911b9cae7600ccafb992b2dbeeddb245c8050031187a8891068379`)
and each run offered 227 / accepted 141 MTP tokens.

Two-run medians, run in the table's order (bridge twice, baseline twice):

| MTP target-hidden prefill bridge | First HTTP byte | First model token | Prefill | Output | Whole GPU 0 sampled peak |
|---|---:|---:|---:|---:|---:|
| Off | 9.93 ms | 28.493 s | 1,763.5 tok/s | 64.25 tok/s | 20,499 MiB |
| On | 14.31 ms | 27.853 s | 1,811.1 tok/s | 66.45 tok/s | 20,499 MiB |

With the bridge enabled, all 25 prefill chunks (50,000 rows) used the GPU
hidden-input path. Its counter reports avoiding 409,395,200 bytes
(390.43 MiB) of whole-chunk GPU-to-host hidden transfer. This is a transfer
count, **not** a measurement of host RAM saved. Whole-GPU sampled peak VRAM did
not change. The bridge only changes the transfer to the draft catch-up input;
it does not chain draft steps or port the original Strata verification/commit
graphs.

The observed differences are small and the arms were run sequentially, not
alternated. They do not establish a stable latency or throughput improvement.
The default path remains off. The separate hidden-time log includes waiting
for asynchronous GPU work and cannot be read as pure PCIe transfer time.
Neither arm reached 100 tok/s.

Each `arms/<name>/runNNN.json` has the request, binary, model, MTP and config
hashes, HTTP and model-token timings, MTP acceptance, output hash, GPU and RAM
samples, and engine counters. Event and resource JSONL files retain the raw
observations. GPU use is whole-card sampling, not process-attributed VRAM.
